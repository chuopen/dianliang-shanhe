# 点亮山河 · 国风中国地理科普互动地图

> 一幅可以点亮的国风水墨中国地图。点击省份，在画卷中"撞见"散落的知识奇遇，答题闯关逐级点亮，从省一路下钻到县。

## 这是什么

「点亮山河」是一个寓教于乐的中国地理科普 Web 应用（原型阶段）：

- **盲盒式奇遇**：每张奇遇卡以一句钩子开场，硬知识以"碎片"逐条点亮，补全后才解锁小测——知识以猝不及防的方式进入脑袋
- **三档点亮**：了解度（探索分 40% + 答题分 60%）达到 40/70/90 触发「微光初现 / 半壁生辉 / 华彩全亮」
- **层级下钻**：省半亮解锁市级、市全亮解锁县级，一路从山东点亮到菏泽九县区
- **双轨收集**：地区冰箱贴 + 奇遇卡牌（N/R/SR/SSR），成就殿堂陈列
- **四套画卷皮肤**：墨渊鎏金（默认）/ 桃源手账 / 仙剑云海 / 碧海群岛，顶栏一键切换
- **考点模式**：开关即切，奇遇带考点角标、题库混入真题风格

## 内容规模

- **34 省级全量 + 13 座明星城市 + 菏泽全境 9 县区**，共 962 条种子奇遇（每条含正文、4~7 个知识碎片、内嵌小测、来源、可信度三档标注：史实 / 民间传说 / 网络热梗）
- 山东闯关题库 2 套（其余省份由奇遇小测自动组卷）
- 内容生产规范见 [`docs/content/CONTENT-SPEC.md`](docs/content/CONTENT-SPEC.md)

## 本地运行

```bash
cd web
python3 server.py        # http://127.0.0.1:8765（自带 no-store 响应头）
```

纯静态前端，无任何构建依赖；进度保存在浏览器 localStorage。
