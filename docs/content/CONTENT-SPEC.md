# 《点亮山河》种子内容生产规范（CONTENT-SPEC）V1.0

> 本规范定义种子奇遇/题库的数据结构、判级标准、可信度标注、内容红线与生产流程。
> 所有种子内容以 JSON 交付（`data/` 目录），可直接被产品加载。

---

## 1. 数据结构（Schema）

### 1.1 地区内容文件（每地区一个 JSON）

```json
{
  "region": {
    "code": "SD",
    "name": "山东",
    "level": "province",        // province | city | county
    "parent": null               // 上级地区 code，省级为 null
  },
  "encounters": [ /* 奇遇对象数组，见 1.2 */ ]
}
```

### 1.2 奇遇对象

> **呈现方式（V2 起生效）**：奇遇卡为"碎片式"呈现——`type` 决定钩子语（"画卷深处，一位故人向你走来"），`content` 首句作为开场引文，`knowledgeDensity` 数组逐条转为可点亮的"知识碎片"（盲盒式），全部碎片补全后才解锁内嵌小测；`content` 全文折叠在"展开细读"里。因此：**`content` 首句务必写成钩子句（有画面感、≤45 字收住），`knowledgeDensity` 每条写成独立可读的短句（12~20 字），不要写成干瘪的词组。**

```json
{
  "id": "SD-001",                       // 地区code-三位序号，全局唯一
  "title": "泰山",                       // 奇遇名
  "type": "山水",                        // 名人 | 风物 | 山水 | 事件 | 热梗 | 考点
  "rarity": "R",                        // N | R | SR | SSR（判级标准见 §2）
  "credibility": "史实",                 // 史实 | 民间传说 | 网络热梗（见 §3）
  "place": "泰安",                       // 关联地（市/县名，用于画卷摆放提示）
  "content": "80~200字精编正文，风格：有趣、通晓古今、有画面感",
  "quote": {                             // 可选：配套诗词/金句（加分项）
    "text": "会当凌绝顶，一览众山小",
    "author": "杜甫",
    "work": "望岳"
  },
  "sources": ["山东省文旅厅官网", "史记"],  // 来源标注（1~3条，AI运行时回答必附来源，种子内容同样要求）
  "quiz": {                              // 可选：内嵌奇遇小测（单选）
    "question": "……？",
    "options": ["A", "B", "C"],
    "answer": 0,                          // 正确选项下标
    "explanation": "答错讲解，含1个关联知识点"
  },
  "examPoint": "高中地理·地貌",            // 可选：考点模式角标文案（初中/高中+学科+知识点）
  "reviewStatus": "pending",             // pending(待人工复核) | verified(已复核)
  "reviewNote": "待复核项说明，如：籍贯精确到县需查证"
}
```

### 1.3 闯关题库文件

```json
{
  "region": "SD",
  "sets": [
    {
      "setId": "SD-SET-01",
      "name": "岱宗问剑·壹",              // 牌坊套题名，与地方绑定
      "questions": [
        {
          "id": "SD-Q001",
          "type": "single",               // single(单选) | boolean(判断)
          "question": "……？",
          "options": ["…", "…", "…", "…"],
          "answer": 1,
          "explanation": "答案依据 + 关联知识点",
          "examPoint": "初中地理·气候",    // 可选；有此字段的题在考点模式下带真题风格角标
          "examMeta": "真题风格·2023济南中考" // 可选：真题风格标注
        }
      ]
    }
  ]
}
```

## 2. 稀有度判级标准（rarity）

| 稀有度 | 标准 | 示例 |
|---|---|---|
| N | 日常风物、常见知识点 | 单县羊汤、青岛啤酒、章丘大葱 |
| R | 知名景点、知名人物、地方名片 | 泰山、黄渤、趵突泉、潍坊风筝 |
| SR | 重大历史事件绑定、文化宗师级人物、重要传说体系 | 虎门·林则徐销烟、孔子、范蠡·定陶、麒麟传说·巨野 |
| SSR | 顶流文化 IP"偶遇"（全国漫游型，出现在任意画卷都有"竟然在这遇到"的惊喜） | 李白、苏轼（每个顶流 IP 全国只放 1~2 处"本尊站"，其余以行踪彩蛋出现） |

**判级三问**：① 不知道它等于没来过这地方吗（是→R+）②它与重大历史/文化坐标绑定吗（是→SR+）③ 属于"全国人民集体记忆"的顶流 IP 吗（是→SSR）。

## 3. 可信度三档标注（credibility）

| 档位 | 标注 | 判定 |
|---|---|---|
| 史实 | 无角标 | 正史/权威方志/官方机构可查 |
| 民间传说 | 🏮"民间传说" | 地方传说、故里争议（如庄子故里多地之争、伯乐籍贯之说）——**必须标**，且正文用"相传/传说"措辞 |
| 网络热梗 | 🔥"网络热梗" | 互联网流行梗（曹县、蓝翔、夏雨荷）——**必须标**，梗的本质注明"网络流行说法" |

## 4. 内容红线自检清单（每条奇遇发布前过一遍）

1. ❌ 在世政治人物（含亲属）——不写、不进题库、不做梗。
2. ❌ 在世人物负面/私生活内容——在世名人只写公开职业成就（作品、成就、公开履历）。
3. ❌ 民族、宗教敏感表述；领土表述以标准地图为准。
4. ❌ 无标注的传说当史实写；无标注的梗当事实写。
5. ✅ 人物籍贯必须精确核验（教训案例：黄晓明、黄渤均为**青岛**人，不是济南）。
6. ✅ 每条内容必须有 sources；拿不准的标 `reviewStatus: pending` 并写明 `reviewNote`。

## 5. 生产流程与分工

```
① AI 初稿（本仓库完成，依据本规范撰写，自身知识为主）
② 事实自检（AI 对籍贯/年代/地点等硬事实逐条自查，存疑的标 pending + reviewNote）
③ 人工复核（需求方抽查：建议优先复核 pending 条目与自己家乡的内容）
④ 定稿（reviewStatus → verified，随版本入库）
```

**元宝搜索 API 在内容生产中的定位**：种子内容生产**不依赖**元宝 API（用 AI 自身知识 + 存疑标注机制）。元宝 API（腾讯云联网搜索 API）用于**产品运行时**（US-08：奇遇追问、长尾奇遇、AI 拓展题）。接入要求见 PRD US-08 与本规范 §7。

## 7. 元宝搜索 API 接入备忘（产品开发期用）

- 服务：腾讯云 **联网搜索 API**（即元宝同款搜索，产品文档 product/1806）
- 接口：`SearchPro`（`tencentcloud.wsa.v20250508`），endpoint：`wsa.tencentcloudapi.com`
- 前置：注册腾讯云并实名 → 控制台**开通联网搜索 API 服务** → 云 API 密钥（SecretId/SecretKey）
- **安全红线**：密钥只放**后端服务**（环境变量/密钥管理系统），**绝不写入前端网页代码**（会被爬取盗刷）；浏览器端一律通过自有后端代理调用
- 调用约束：所有 AI 回答必须附来源（接口返回摘要卡片带链接）；命中红线词库的追问直接拦截不生成；相同问题走缓存（PRD US-08 缓存沉淀）
